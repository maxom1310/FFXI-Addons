# FFXI-Addons
FFXI Addons Some Modified using AI
ROE - Modified can load to all or party and has Mirror option to manually load to all.
Sparky - Modified with a GUI HUD added and can do prize powder.  Added a checks for the 100k weekly cap
Focus - New addon to use macros with <ft> as target where you can set a focus target. Adds a HP bar for your focus target. Good for TP battery fights like Mboze
Pouches - Modified with GUI HUD and pause / stop options. Auto-pause when inventory full as well
Entruster - New addon GUI HUD to entrust set party members for prebuffing Odyssey fights.  It will auto swap to geo if you arent on geo and swap back to original job you were on.
